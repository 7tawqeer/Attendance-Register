# 📋 Attendance Registry

A streamlined web application designed to simplify the daily tracking of student attendance. This project was developed as a practical application of core web technologies for the Bachelor of Computer Applications (BCA) program at Government Degree College, Pulwama.

## ✨ Project Overview

Managing attendance records manually can be tedious and prone to errors. This registry provides a clean, user-friendly interface to quickly log, review, and manage daily student attendance without the hassle of physical paperwork.

### Key Features
* **Quick Logging:** Mark students as present or absent with a simple, intuitive interface.
* **Accessible Anywhere:** Fully deployed and accessible via the web, meaning records can be updated from any device.
* **Digital Record Keeping:** Transitions traditional pen-and-paper tracking into an efficient digital format.
